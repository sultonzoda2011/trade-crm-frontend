# Продавцы и пользователи

Это два взгляда на учётные записи людей, которые работают в системе.

- **«Продавцы»** — сотрудники рынка, которые оформляют продажи. Ими управляют администратор и владелец.
- **«Пользователи»** — все учётные записи с ролями. Этот раздел доступен только администратору.

По сути это одни и те же аккаунты, просто показанные с разных сторон.

## Продавцы

В списке продавцов видны столбцы:

| Столбец | Что показывает |
| --- | --- |
| Название | Имя, аватар и почта продавца |
| Электронная почта | Адрес для входа |
| Рынок | На каком рынке работает |

Напротив строки — действия: открыть карточку, изменить, удалить.

### Как добавить продавца

Нажмите **«Создать продавца»** и заполните:

- **«Изображение»** — фото сотрудника.
- **«Полное имя»** `*` — имя продавца.
- **«Электронная почта»** `*` — по ней он будет входить в систему.
- **«Пароль»** `*` — первый пароль для входа.

При изменении продавца поле пароля **необязательное**: оставьте его пустым, чтобы пароль не менялся, или впишите новый, чтобы сбросить.

### Надбавки продавца

Откройте карточку продавца — кроме основных данных там есть блок **«Баланс по надбавкам»**. Надбавка — это сумма, которую продавец добавляет к цене при продаже (поле «Надбавка» в сделке). Она копится как его заработок.

| Показатель | Что означает |
| --- | --- |
| Накоплено | Сколько надбавок начислено всего |
| Откачено возвратами | Сколько списано из-за возвратов |
| Уже выдано | Сколько денег уже выплачено продавцу |
| К выдаче | Сколько осталось выплатить сейчас |

### Как выдать надбавку

Когда есть что выплатить (**«К выдаче»** больше нуля), в карточке появляется кнопка **«Выдать»**. Она открывает окно **«Выдать надбавку»**:

- **«Сумма оплаты»** `*` — сколько выплачиваете (не больше суммы к выдаче).
- **«Примечание»** — необязательная заметка.

После выплаты баланс уменьшится на выданную сумму.

## Пользователи

Раздел **«Пользователи»** доступен только администратору. Здесь видны все учётные записи и их роли.

| Столбец | Что показывает |
| --- | --- |
| Название | Имя и аватар |
| Электронная почта | Адрес для входа |
| Роль | Цветной значок роли (см. ниже) |

Столбец **«Рынок»** скрыт (включается кнопкой «Столбцы»). Списки можно отфильтровать по роли, рынку и владельцу.

Значки ролей окрашены по-разному, чтобы их было легко различать:

| Роль | Цвет | Что может |
| --- | --- | --- |
| Администратор | Фиолетовый | Полный доступ ко всему |
| Владелец | Жёлтый | Управляет своим рынком |
| Продавец | Голубой | Оформляет продажи на своём рынке |

### Как добавить пользователя

Нажмите **«Создать пользователя»** и заполните:

- **«Изображение»** — фото.
- **«Роль»** `*` — Администратор, Владелец или Продавец.
- **«Полное имя»** `*` — имя человека.
- **«Электронная почта»** `*` — адрес для входа.
- **«Пароль»** `*` — первый пароль. Рядом есть значок глаза — нажмите, чтобы показать или скрыть введённый пароль.

При изменении пользователя пароль вводить необязательно — оставьте поле пустым, чтобы не менять его.

## О паролях и доступе

> [!NOTE]
> Отдельной кнопки «сбросить пароль» и функции «заблокировать/разблокировать» в программе нет. Пароль задаёт администратор (или владелец — для продавца) при создании, а сменить его можно, отредактировав учётную запись и вписав новый пароль.

## Кто что может

| Действие | Администратор | Владелец | Продавец |
| --- | --- | --- | --- |
| Смотреть продавцов | да | да | нет |
| Создавать и изменять продавцов | да | да | нет |
| Удалять продавца | да | да | нет |
| Выдавать надбавку | да | да | нет |
| Работать с разделом «Пользователи» | да | нет | нет |

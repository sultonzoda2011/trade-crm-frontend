# Фурӯш ва муомилотҳо

Муомила (транзаксия) — як амалиёти савдо мебошад: фурӯш бо пули нақд ё корт, фурӯш ба қарз ё бозгашти мол. Ҳамаи ҳаракати мол ва пул аз бахши **«Муомилотҳо»** (`/transactions`) мегузарад. Дар телефон инчунин аз дилхоҳ ҷой бо пахши тугмаи марказии **«+»** дар панели поёнӣ муомилаи нав сохтан мумкин аст.

## Муомилотҳо чӣ гуна нишон дода мешаванд

Ба ҷои рақамҳои нофаҳмо ба мисли «№1523», ҳар як муомила бо **аксҳои хурди молҳо** ва номи фаҳмо — номи қарздор, номи харидор ё намуди амалиёт — нишон дода мешавад.

> [!TIP]
> Нишондиҳандаи мушро ба гурӯҳи аксҳои молҳо баред (ё дар телефон ба он зер кунед) — рӯйхати дақиқи молҳо ва миқдори онҳо дар ҳамон муомила пайдо мешавад.

## Рӯйхати муомилотҳо, филтрҳо ва лағжиш (свайп)

Дар ҷадвал сутунҳои зерин намоёнанд:

| Сутун | Чиро нишон медиҳад |
| --- | --- |
| **Молҳо** | Аксҳои хурди молҳо ва номи муомила |
| **Қарздор** | Номи қарздор (барои фурӯш ба қарз) |
| **Харидор** | Номи харидор, агар ворид шуда бошад |
| **Намуд** | Фурӯш, Қарз ё Бозгардонӣ |
| **Маблағ** | Маблағи умумии муомила |
| **Ҳолат** | Вазъи кунунии пардохт ё бозгашт |

Бо тугмаи **«Сутунҳо»** метавон сутунҳои иловагиро фаъол кард: **«Усули пардохт»**, **«Боқимонда»**, **«Эҷодкунанда»** ва **«Санаи сохтан»**.

### Ҷустуҷӯ ва филтрҳо

Дар болои рӯйхат сатри ҷустуҷӯ ва тугмаи **«Филтрҳо»** ҷойгиранд. Муомилотҳоро аз рӯи инҳо ҷудо кардан мумкин аст:
- қарздор, категория ё моли мушаххас;
- **намуди муомила** (`Фурӯш`, `Қарз`, `Бозгардонӣ`) ва **усули пардохт** (`Нақд`, `Корт`, `Кредит`);
- **ҳолат** (`Фаъол`, `Қисман`, `Пардохт шуд`, `Қисман бозгардонида шуд`, `Бозгардонида шуд`);
- **«Ҳолати қарз»** (`Мӯҳлаташ гузашта`, `Мӯҳлаташ наздик`, `Пардохт нашуда`, `Пардохт шуда`);
- корманд дар майдони **«Эҷодкунанда»** (барои маъмур ва соҳиб);
- фосилаи маблағ ва фосилаи санаҳо.

### Амалҳои лағжиш ба чап дар телефон

Дар рӯйхати мобилӣ сатри муомиларо **ба тарафи чап кашед** (ё ним сония пахш карда нигоҳ доред):
- **«Пардохт кардан»** (тугмаи сабз) — барои қарзҳои пардохтнашуда (барои маъмур ва соҳиб);
- **«Нест кардан»** (тугмаи сурх бо тасдиқ).

> [!NOTE]
> Муомила тугмаи «Таҳрир» надорад: фурӯш ё қарзи сабтшударо тағйир додан мумкин нест. Агар муштарӣ молро баргардонад — **бозгардонидани мол** ва агар пул оварад — **пардохт** сабт мешавад.

### Намудҳо ва ҳолатҳо

| Намуд / Ҳолат | Чӣ маъно дорад |
| --- | --- |
| **Фурӯш** (сабз) | Мол фурӯхта шуд ва дарҳол нақд ё бо корт пардохт гардид |
| **Қарз** (зард) | Мол ба қарз дода шуд, пардохт то мӯҳлати муайяншуда интизор аст |
| **Бозгардонӣ** (сурх) | Баргардонидани моли пештар фурӯхташуда |
| **Фаъол** | Қарз кушода аст, ҳанӯз пардохте нашудааст |
| **Қисман** | Қисми маблағ пардохт шудааст, боқимонда ҳанӯз ҳаст |
| **Пардохт шуд** | Муомила пурра пӯшида шудааст |
| **Қисман бозгардонида шуд** | Қисми мол ба анбор баргашт, боқимонда дар қувваи худ мемонад |
| **Бозгардонида шуд** | Ҳамаи молҳои муомила пурра баргардонида шуданд |

## Чӣ тавр фурӯш ё қарзро сабт кардан

Тугмаи **«Сохтани муомила»** (ё тугмаи **«+»** дар поёни телефон)-ро зер кунед:

1. **Дар боло усули пардохтро интихоб кунед:** **«Нақд»**, **«Корт»** ё **«Қарз»**. Барнома интихоби охирини шуморо дар хотир нигоҳ медорад.
   - Барои **фурӯшанда** танҳо реҷаи **«Қарз»** фаъол аст.
   - Агар шумо аз корти қарздор бо тугмаи **«Қарз додан»** омада бошед, реҷаи **«Қарз»** ва худи қарздор худкор интихоб шудаанд.
2. **Агар «Қарз» интихоб шуда бошад — қарздор ва мӯҳлатро нишон диҳед:**
   - Ба майдони **«Қарздор»** `*` зер кунед — пардаи ҷустуҷӯ кушода мешавад. Агар шахс ҳанӯз дар рӯйхат набошад, рост дар дохили парда тугмаи **«Қарздори нав»**-ро зер карда, ӯро бе гум кардани форма илова намоед.
   - **«Мӯҳлати пардохт»** `*`-ро аз тақвим ё бо тугмаҳои зуд интихоб кунед: **`+7 рӯз`**, **`+14 рӯз`** ё **`+30 рӯз`**.
3. **Молҳоро илова кунед.** Ба майдони мол зер кунед, то пардаи интихоб бо акс, нарх ва боқимонда кушода шавад.
   - Миқдорро бо тугмаҳои **`−` / `+`** танзим кунед. Дар зери ҳар сатр боқимондаи анбор нишон дода мешавад.
   - Барои илова кардани тахфиф ё иловапулии фурӯшанда тугмаи **«Тахфиф / Иловапулӣ»**-ро зер кунед — майдонҳои **«Тахфиф»** ва **«Иловапулӣ»** кушода мешаванд (`нарх × миқдор − тахфиф + иловапулӣ`).
   - Бо тугмаи **«+ Иловаи мол»** молҳои дигарро илова намоед.
4. **Маблағро санҷед ва сабт кунед.** Дар поён тугмаи **«Анҷоми фурӯш»** (барои нақд/корт) ё **«Сабти қарз»** (барои қарз)-ро зер кунед.

> [!TIP]
> Фурӯш ва қарзро **бе интернет** низ сабт кардан мумкин аст — он фавран дар рӯйхат бо нишони **«Дар навбат»** пайдо мешавад ва пас аз пайдо шудани алоқа худаш ба сервер меравад.

## Саҳифаи муфассали муомила

Зер кардан ба дилхоҳ сатр корти муомиларо (`/transactions/:id`) мекушояд, ки дар он инҳо ҳастанд:
- сарлавҳа бо аксҳои молҳо, ҳолат, санаҳо ва тугмаҳои **«Пардохт кардан»**, **«Бозгардонидани мол»**, **«Нест кардан»**;
- ҷадвали **«Молҳо»** ва блоки **«Қарздор»**;
- **«Таърихи пардохтҳо»** ва **«Таърихи бозгаштҳо»**;
- **«Ҷамъбасти муомила»** ва **«Хронология»** (силсилаи ҳамаи рӯйдодҳо аз лаҳзаи сохтан).

## Чӣ тавр пардохти қарзро қабул кардан

Пардохтро аз рӯйхати муомилотҳо, аз саҳифаи муомила (**«Пардохт кардан»**) ё рост аз корти қарздор (**«Қабули пардохт»**) ворид кардан мумкин аст:
1. Дар равзана тугмаи зуди **«Тамоми боқимонда»** ё **«Ним»**-ро зер кунед ва ё дилхоҳ маблағро дастӣ нависед.
2. Агар лозим бошад, **«Эзоҳ»** илова кунед.
3. Тугмаи **«Пардохт кардан · [Маблағ] TJS»**-ро зер кунед.

## Чӣ тавр бозгашти молро ба расмият даровардан

Дар саҳифаи муомила тугмаи **«Бозгардонидани мол»**-ро зер кунед:
1. Интихоб намоед: **«Тамоми боқимондаро»** ё **«Сатрҳои интихобшуда»** (бо нишон додани миқдори ҳар як мол).
2. **«Сабаби бозгашт»** `*`-ро нависед ва тасдиқ кунед.

Моли баргардонидашуда худкор ба анбор илова мешавад ва маблағи муомилаву қарз аз нав ҳисоб мегардад.

| Сабти муомила ба «Қарз» | Ҳа | Ҳа | Ҳа |
| Ба расмият даровардани фурӯш (Нақд / Корт) | Ҳа | Ҳа | Не |

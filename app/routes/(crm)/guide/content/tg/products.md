# Молҳо ва категорияҳо

Бахши **«Молҳо»** (`/products`) — каталоги дӯкони шумо бо нархҳо, воҳидҳои ченак, боқимондаи анбор ва баҳодиҳии ҳушманди захираҳо мебошад. Бахши **«Категорияҳо»** (`/categories`) имкон медиҳад, ки молҳоро аз рӯи гурӯҳҳо (масалан, «Нӯшокиҳо», «Хӯрокворӣ», «Молҳои рӯзгор») ҷудо намоед.

> [!NOTE]
> Дидани каталог ва кортҳои молҳо барои ҳамаи нақшҳо, аз ҷумла **фурӯшанда** (барои санҷидани нарх ва боқимонда дар анбор) дастрас аст. Сохтан, пур кардан, таҳрир ва нест кардани молҳо, инчунин идоракунии категорияҳо танҳо барои **маъмур** ва **соҳиб** иҷозат дода шудааст.

## Рӯйхати молҳо ва намуди мобилӣ

Дар компютер дар ҷадвал сутунҳои зерин намоёнанд:

| Сутун | Чиро нишон медиҳад |
| --- | --- |
| **Ном** | Акс ва номи мол |
| **Нарх** | Нархи фурӯш барои як воҳид |
| **Миқдор** | Боқимондаи ҷорӣ дар анбор (ҳангоми расидан ба ҳадди ақал сурх мешавад) |
| **Ҳолат** | Вазъи захираи мол |
| **Таъҷилии харид** | Тавсия барои фармоиши нав |

Бо тугмаи **«Сутунҳо»** сутунҳои иловагиро фаъол кардан мумкин аст: **«Захира ба ҳисоби рӯз»**, **«Фурӯхта шуд»**, **«Даромад»**, **«Категория»**, **«Бозор»**, **«Муомилотҳо»** ва **«Санаи сохтан»**.

### Сатри фишурда ва лағжиш дар телефон

Дар телефон ҳар як мол дар шакли сатри қулай бо акс, ном, категория, нарх, миқдор ва **нишондиҳандаи ягонаи ҳолат** нишон дода мешавад:
- **«Нест»** (сурх) — мол тамом шудааст;
- **«Кам · X рӯз»** (сурх) — захираи критикӣ;
- **«Ба зудӣ · X рӯз»** (зард) — вақти банақшагирии харид;
- **«Бозгашт»** (зард) — бозгардонидани зиёд;
- **«Хоб аст»** (хокистарӣ) — суст фурӯхта мешавад;
- **нуқтаи сабз бо шумораи рӯзҳо** (ё `>1 с.`) — захира кофӣ аст.

Дар телефон сатри молро **ба тарафи чап кашед** (ё ним сония пахш карда нигоҳ доред), то тугмаҳои **«Пур кардан»**, **«Таҳрир»**, **«Ба бойгонӣ»** ва **«Нест кардан»** кушода шаванд (барои маъмур ва соҳиб; «Нест кардан» — танҳо барои моли бе фурӯш).

### Филтрҳо ва «Давраи ҳисоб»

Дар болои рӯйхат ҷустуҷӯ ва тугмаи **«Филтрҳо»** кор мекунанд. Филтри **«Давраи ҳисоб»** фосилаи вақтеро мегузорад, ки аз рӯи он суръати фурӯш, даромад ва пешгӯии **«Захира ба ҳисоби рӯз»** ҳисоб карда мешавад.

### Ҳолати мол ва таъҷилии фармоиш

| Ҳолат / Таъҷилӣ | Чӣ маъно дорад |
| --- | --- |
| **Дар меъёр** / **Захира кифоя аст** | Мол хуб фурӯхта мешавад ва дар анбор кофӣ аст |
| **Дар анбор кам** / **Ба зудӣ фармоиш диҳед** | Миқдор ба ҳадди ақал наздик шудааст |
| **Захираи критикӣ** / **Фавран фармоиш диҳед** | Захира хеле кам мондааст, дар навбати аввал пур кунед |
| **Мавҷуд нест** / **Тамом шуд** | Дар анбор 0 воҳид мондааст |
| **Бозгардонидан зиёд** | Харидорон ин молро тез-тез бармегардонанд |
| **Суст фурӯхта мешавад** / **Фурӯш нест** | Мол суст меравад ё дар давраи интихобшуда фурӯхта нашудааст |

## Корти мол ва пур кардани зуд («Пур кардан»)

Ба дилхоҳ мол зер кунед, то саҳифаи муфассали онро (`/products/:id`) кушоед. Дар болои корт се тугма ҷойгир аст:

- **«Пур кардан»** — амали асосӣ ҳангоми омадани бори нав ба анбор;
- **«Таҳрир»** — тағйир додани ном, нарх, нархи харид, тавсиф ва акс (миқдор дар ин ҷо тағйир намеёбад — поёнтар бинед);
- **«Нест кардан»** — пок кардани мол бо тасдиқ.

### Чӣ тавр миқдори молро пур кардан

Вақте ба анбор моли нав меояд, лозим нест онро дар фикр ҷамъ кунед:

1. Корти молро кушоед ва тугмаи **«Пур кардан»**-ро зер кунед.
2. Дар равзанаи **«Пур кардан: [Номи мол]»** дар майдони **«Чанд адад илова мешавад»** миқдори омадаро нависед ё яке аз тугмаҳои зудро пахш намоед: **`+10`**, **`+50`**, **`+100`**.
3. Дар поён фавран ҳисоб нишон дода мешавад: **«Ҳоло дар анбор»** → **«Мешавад»**.
4. Тугмаи **«Илова кардан»**-ро зер кунед — миқдори нав худкор ба бақияи ҷорӣ ҷамъ мешавад.

> [!TIP]
> Тугмаи **«Пур кардан»** рақамро ба миқдори ҳозира **илова мекунад**. Агар аз нав шумурда бошед ва рақам нодуруст бошад, **«Аз нав шумурдан»**-ро истифода баред (поёнтар бинед).

## Миқдор зери назорат: хориҷкунӣ, аз нав шумурдан, таърих

Миқдори мол танҳо бо чор роҳ тағйир меёбад ва ҳар кадом дар **«Таърихи миқдор»**-и саҳифаи мол сабт мешавад (кӣ, кай, чанд адад ва пас аз он чӣ қадар монд): **фурӯш/бозгашт**, **«Пур кардан»**, **«Хориҷ кардан»**, **«Аз нав шумурдан»**. Тавассути шакли таҳрир миқдорро иваз кардан мумкин нест — барои ҳамин дар таърих ҳамеша маълум аст, ки мол ба куҷо рафт. Блоки **«Идораи миқдор»** ва таърих барои маъмур ва соҳиб дастрас аст.

- **«Хориҷ кардан»** — вайрон, мӯҳлаташ гузашт, гум шуд ё дуздида шуд, барои худам, дигар. Миқдор ва сабабро нависед (эзоҳ ихтиёрӣ). Аз миқдори дар анбор буда зиёд хориҷ кардан мумкин нест.
- **«Аз нав шумурдан»** — шумо рафро шумурдед ва мефармоед, ки **дар асл** чанд адад ҳаст (шумораи ниҳоӣ, на иловаро). Барнома фарқиятро бо ҳисоб нишон медиҳад ва дар таърих сабт мекунад. Агар ҳангоми шумурдан фурӯш гузашта бошад, миқдор нав мешавад ва барнома хоҳиш мекунад, ки рақамро боз ворид кунед.

### Бойгонӣ ба ҷои нест кардан

Моле, ки аллакай фурӯхта шудааст, **нест карда намешавад** — чекҳо ба он истинод мекунанд. Ба ҷои ин **«Ба бойгонӣ»**-ро пахш кунед (дар саҳифаи мол ё бо лағжиш дар сатр). Моли бойгонӣ аз рӯйхат ва фурӯш нопадид мешавад ва ба ҳисоботи анбор дохил намешавад, вале таърих ва чекҳои пештара мемонанд. Барои дидани бойгонӣ дар болои рӯйхат **«Намоиш → Бойгонӣ»**-ро интихоб кунед; молро бо тугмаи **«Аз бойгонӣ баргардондан»** бармегардонед. Моле, ки ҳеҷ гоҳ фурӯхта нашудааст, ҳамоно нест карда мешавад.

### Ҳисоботи анбор ва тағйири оммавии нархҳо

Дар болои рӯйхат (барои маъмур ва соҳиб) се рақам аз рӯи ҳамаи молҳои фаъол нишон дода мешавад: **«Молҳо»**, **«Анбор»** (арзиши боқимонда бо нархи чакана) ва **«Фоида»** (дар боқимонда чӣ қадар кор кардан мумкин аст). Фоида танҳо аз рӯи молҳои нархи харид дошта ҳисоб мешавад, бинобар ин шумораи молҳои бе он дар паҳлӯ нишон дода мешавад. **«Нест: N»** ё **«Кам: N»**-ро пахш кунед, то рӯйхати чунин молҳо кушода шавад.

Тугмаи **«Нархҳо»** нархи бисёр молҳоро якбора иваз мекунад: фоизро ворид кунед (масалан, `+5` ё `−10`), дилхоҳ категория ва қадами мудаввар карданро интихоб намоед, **«Санҷидан»**-ро пахш кунед, то бинед чӣ тағйир меёбад, пас **«Татбиқ»**-ро. Нархи харид ва чекҳои гузашта тағйир намеёбанд, молҳои бойгонӣ гузаронида мешаванд.

## Чӣ тавр моли нав сохтан

Тугмаи **«Эҷоди мол»** (`/products/create`)-ро зер кунед ва майдонҳоро пур намоед:

- **«Тасвир»** — акси мол.
- **«Ном»** `*` — номи мол.
- **«Категория»** — гурӯҳи мол (ихтиёрӣ).
- **«Нарх»** `*` — нархи як воҳид.
- **«Нархи харид»** — мол бо чанд харида мешавад; барои ҳисоби фоида лозим аст ва танҳо маъмур ва соҳиб мебинанд.
- **«Миқдори аввалия»** `*` — ҳоло чанд адад дар анбор ҳаст; баъд миқдорро «Пур кардан», «Хориҷ кардан» ва «Аз нав шумурдан» тағйир медиҳанд.
- **«Воҳиди ченак»** — **дона**, **кг**, **л**, **м** ё **қуттӣ**.
- **«Ҳадди камшавии захира»** — миқдоре, ки ҳангоми расидан ба он барнома огоҳӣ медиҳад.
- **«Тавсиф»** — маълумоти мухтасар дар бораи мол (ихтиёрӣ).

## Категорияҳо

Дар бахши **«Категорияҳо»** (`/categories`) гурӯҳҳои молҳо идора карда мешаванд:
- Тугмаи **«Эҷоди категория»** саҳифаи `/categories/create`-ро бо майдонҳои **«Тасвир»**, **«Ном»** `*` ва **«Тавсиф»** мекушояд.
- Зер кардан ба категория саҳифаи онро (`/categories/:id`) бо рӯйхати молҳои ҳамон гурӯҳ ва тугмаҳои **«Таҳрир»** ва **«Нест кардан»** мекушояд.

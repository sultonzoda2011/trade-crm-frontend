# Молҳо ва категорияҳо

Молҳо — ин ҳама чизест, ки шумо мефурӯшед. Бахши **«Молҳо»**-и менюи чап — ин каталоги шумост: нархҳо, бақияҳо дар анбор ва ишораҳо дар бораи он ки чиро харидан лозим аст. Категорияҳо кӯмак мекунанд, ки молҳо гурӯҳбандӣ шаванд (масалан, «Нӯшокиҳо», «Маводи кимиёвии маишӣ»).

> [!NOTE]
> Молҳо ва категорияҳоро администратор ва соҳиб идора мекунанд. Фурӯшанда ҳангоми ба расмият даровардани фурӯш молҳоро интихоб мекунад, вале худи каталогро таҳрир намекунад.

## Рӯйхати молҳо

Дар рӯйхат ба таври пешфарз ин сутунҳо дида мешаванд:

| Сутун | Чиро нишон медиҳад |
| --- | --- |
| Ном | Тасвир ва номи мол |
| Нарх | Нарх барои як воҳид |
| Миқдор | Чанд дар анбор (агар бақия дар остона ё пасттар бошад, сурх мешавад) |
| Ҳолат | Саломатии мол: дар меъёр, кам, критикӣ ва ғайра |
| Таъҷилияти харид | Оё харидан лозим аст ва то чӣ андоза таъҷилӣ |

Сутунҳои иловагиро бо тугмаи **«Сутунҳо»** фаъол кардан мумкин аст: **«Захира бо рӯз»**, **«Фурӯхташуда»**, **«Даромад»**, **«Категория»**, **«Бозор»**, **«Транзаксияҳо»**, **«Санаи сохтан»**.

### Давраи ҳисоб

Дар болои рӯйхат филтри **«Давраи ҳисоб»** ҳаст. Фаҳмидан муҳим аст: он **тирезаеро муайян мекунад, ки дар он нишондиҳандаҳо ҳисоб мешаванд** — чанд фурӯхта шуд, кадом даромад, захира ба чанд рӯз мерасад. Ин **на** санаи илова шудани мол аст. Масалан, «барои 30 рӯз»-ро интихоб карда, шумо маҳз фурӯш ва даромади моҳи охирро мебинед, вале худи молҳо ҳама боқӣ мемонанд.

### Ҳолати мол

Барнома «саломатии» ҳар молро худаш баҳо медиҳад ва нишонаи рангин нишон медиҳад:

| Нишона | Чӣ маъно дорад |
| --- | --- |
| Дар меъёр | Ҳама чиз хуб аст — мол фурӯхта мешавад ва дар анбор ҳаст |
| Дар анбор кам | Бақия ба остона наздик мешавад — ба зудӣ тамом мешавад |
| Бақияи критикӣ | Хеле кам мондааст |
| Дар мавҷудӣ нест | Мол дар анбор нест |
| Бозгашти зиёд | Молро зуд-зуд бармегардонанд — фаҳмидан лозим аст |
| Суст фурӯхта мешавад | Дар анбор мехобад, суст фурӯхта мешавад |
| Фурӯш нест | Дар давраи интихобшуда ягон фурӯш набуд |

### Таъҷилияти харид

Дар паҳлӯ барнома ишора мекунад, ки чиро харидан лозим аст:

| Нишона | Чӣ маъно дорад |
| --- | --- |
| Фавран фармоиш диҳед | Бақия критикӣ аст — дар навбати аввал харед |
| Ба зудӣ фармоиш диҳед | Ба зудӣ тамом мешавад — харидро ба нақша гиред |
| Тамом шуд | Мол нест — пур кардан лозим аст |
| Захира кофист | Ҳоло харидан лозим нест |
| Фармоиш лозим нест | Мол ба пур кардан ниёз надорад |

## Чӣ тавр мол илова кардан

Тугмаи **«Сохтани мол»**-ро зер кунед ва формаро пур кунед:

- **«Тасвир»** — акси мол (аз дастгоҳ бор карда мешавад).
- **«Ном»** `*` — мол чӣ ном дорад.
- **«Категория»** — ба кадом гурӯҳ мансуб аст (метавон холӣ гузошт).
- **«Нарх»** `*` — нарх барои як воҳид, на камтар аз 1.
- **«Миқдор»** `*` — ҳоло чанд дар анбор, на камтар аз 0.
- **«Воҳиди ченак»** — мол дар чӣ ҳисоб мешавад (ба таври пешфарз «дона»).
- **«Остонаи бақияи кам»** — дар кадом миқдор мол тамомшаванда ҳисобида шавад.
- **«Тавсиф»** `*` — тавсифи мухтасари мол.

> [!IMPORTANT]
> Майдонҳои ҳатмӣ бо ситорача `*` ишора шудаанд: ном, нарх, миқдор ва тавсиф. Бе онҳо молро нигоҳ доштан мумкин нест.

Воҳидҳои ченак:

| Ишора | Маъно |
| --- | --- |
| дона | донаҳо |
| кг | килограмм |
| л | литр |
| м | метр |
| қуттӣ | қуттиҳо |

> [!TIP]
> **«Остонаи бақияи кам»** — ҳимояи қулай аз он ки мол ногаҳон тамом нашавад. Ҳамин ки миқдор то остона ё пасттар фарояд, рақам сурх мешавад, ва мол нишонаи «Дар анбор кам» ва ишораи харидро мегирад.

## Тасвири мол

Акс рост аз телефон ё компютер бор карда мешавад. Он дар рӯйхат ва дар корти мол, инчунин ҳамчун аватари хурд дар транзаксияҳое, ки ин мол фурӯхта шуда буд, нишон дода мешавад.

## Категорияҳо

Категорияҳо — гурӯҳҳои молҳо ҳастанд. Категория **«Тасвир»**, **«Ном»** `*` ва **«Тавсиф»** дорад. Категорияҳо дар равзанаҳои алоҳидаи барояндагӣ сохта ва таҳрир мешаванд. Барои ба категория мансуб кардани мол, онро дар майдони **«Категория»** ҳангоми сохтан ё тағйир додани мол интихоб кунед.

Категорияҳо кӯмак мекунанд, ки молҳо тезтар ёфта шаванд ва рӯйхатҳову ҳисоботҳо аз рӯи гурӯҳҳо филтр карда шаванд.

## Кӣ чӣ карда метавонад

| Амал | Администратор | Соҳиб | Фурӯшанда |
| --- | --- | --- | --- |
| Дидани каталоги молҳо | ҳа | ҳа | не |
| Сохтан, тағйир додан, нест кардани молҳо | ҳа | ҳа | не |
| Идораи категорияҳо | ҳа | ҳа | не |
| Интихоби мол ҳангоми фурӯш | ҳа | ҳа | ҳа |

> [!NOTE]
> Фурӯшанда ба бахши молҳо ва категорияҳо ҳамчун каталог дастрасӣ надорад — ҳангоми кӯшиши воридшавӣ ӯ паёми «Дастрасӣ манъ аст»-ро мебинад. Вале ҳангоми ба расмият даровардани фурӯши қарзӣ молҳоро интихоб карда метавонад.
